Build your first "chat with your documents" system, one component at a time. Each part: watch it fail, play with a live demo, then run the code.

What you will build

  • Chunking: fixed size, overlap and recursive splitting
  • Embeddings: turning text into numbers that capture meaning
  • A vector index with FAISS, and keyword search with BM25
  • Hybrid search: fusing the two rankings
  • Generation: a grounded prompt with citations, on a local model via Ollama
  • Evaluation with Ragas, and when a long context window beats RAG
